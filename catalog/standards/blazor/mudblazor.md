# MudBlazor guidance

**Applies to:** Blazor projects using MudBlazor.

- Use the component API from the version actually installed in the project.
- Choose components based on interaction semantics and accessibility, not merely visual similarity.
- Verify validation and error messages with keyboard and assistive technology scenarios.
- Keep styling tokens consistent; do not override library internals unnecessarily.
- Record app-specific theming and service registration in the project rather than a universal standard.
