# Scalar API Reference for ASP.NET Core

**Applies only when the profile is selected.** Not an approved architecture by itself.

## Guidance

Scalar.AspNetCore displays an existing OpenAPI document, including Microsoft-built-in or Swashbuckle output. Configure MapScalarApiReference and the actual OpenAPI route. Restrict access appropriately and never embed production credentials.

## Verification

Verify installed versions and real contracts. Test integration and security boundaries separately.
