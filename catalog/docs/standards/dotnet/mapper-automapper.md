# AutoMapper mapping

**Scope:** Select this option explicitly in the wizard; a catalog entry alone does not prove an implementation exists.

## Guidance

Use explicit mapping profiles for justified object transformations; avoid hidden mappings of sensitive or server-owned properties. Verify the package license for the adopted version. When using projections with IQueryable, confirm translation by the actual ORM provider; compiled object mapping and SQL projection are different behaviors.

## Verification

Record actual versions, authoritative sources and executed tests. Do not import historical product-specific entities or workflows into reusable guidance.
