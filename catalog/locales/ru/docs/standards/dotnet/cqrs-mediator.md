# CQRS с martinothamar/Mediator

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Используйте source-generated регистрацию и контракты Mediator для фактической версии. Подключайте генератор в соответствующем composition-проекте, а не в каждой библиотеке. При необходимости проверяйте Native AOT; диагностика компиляции не заменяет поведенческие тесты handlers.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
