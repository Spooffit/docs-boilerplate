# Маппинг через Mapster

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Выберите настройку Mapster adapters или поддерживаемую версией генерацию на этапе компиляции. Явно фиксируйте соглашения, nullability, вложенные значения и границы публичного контракта. Поведение проекций проверяйте на настоящем query provider; не все выражения переводятся в SQL.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
