# MassTransit Kafka Rider

**Применимость:** только при явном выборе соответствующей технологии. Это универсальные рекомендации, а не бизнес-требования или доказательство реализации.

## Проектирование и ответственность

Kafka Rider расширяет шину MassTransit; отличайте topic endpoints и consumer groups от очередей RabbitMQ. Регистрируйте rider через публичные API установленной версии MassTransit. Определяйте offsets/commits, партиционирование, повторы, ошибки, версии сообщений и границы тестов. Контракт Kafka-consumer не наследует автоматически транзакционные гарантии другой шины. Проверяйте маршрутизацию на тестовом Kafka.

## Доказательства

Фиксируйте фактически установленные версии и авторитетные контракты. Не считайте нерешённые вопросы принятыми. При важном внешнем поведении проверяйте реальные интеграции; сгенерированная документация не доказывает работу приложения.
