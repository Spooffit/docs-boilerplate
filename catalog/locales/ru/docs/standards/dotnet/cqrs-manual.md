# Ручные CQRS-обработчики

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Реализуйте команды и запросы через прикладные handlers или Minimal API без обязательной библиотеки mediator. Разделяйте запись и чтение, соблюдайте авторизацию и доменные инварианты, не превращайте endpoints в большие сервисы. Передавайте отмену и явные ошибки; вводите pipeline-абстракции только при подтверждённой потребности.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
