# CQRS на обработчиках Wolverine

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Используйте локальные handlers Wolverine только если Wolverine уже выбран для сообщений. Локальные команды и запросы не требуют отправки через брокер; определите, какие сообщения локальные, а какие пересекают транспорт. Проверяйте middleware транзакций, обнаружение handlers, отмену, идемпотентность и ошибки установленной версии.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
