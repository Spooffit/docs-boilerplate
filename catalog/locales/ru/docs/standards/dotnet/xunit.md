# xUnit.net: тестирование .NET

**Применяется при явном выборе xUnit.net.** Это альтернатива TUnit: выбирайте только один базовый тестовый фреймворк.

- Используйте [Fact] для тестов без параметров, [Theory] и атрибуты данных — для параметризованных случаев.
- Пишите детерминированные проверки наблюдаемого поведения, избегайте общего изменяемого состояния между тестами.
- Асинхронные тесты возвращают Task, не блокируются через Result или Wait.
- Явно управляйте жизненным циклом фикстур (конструктор, IAsyncLifetime, collection fixtures). Не опирайтесь на порядок запуска.
- Отделяйте модульные тесты от интеграционных, требующих реальных ресурсов. Testcontainers и Aspire testing выбираются независимо.
- Используйте действительно установленные версии SDK, runner и xUnit. Не предполагается конкретная major-версия xUnit.

Источники: [xUnit](https://xunit.net/) и [dotnet test](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-test).
