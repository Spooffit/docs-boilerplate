# Маппинг через AutoMapper

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Используйте явные профили отображения объектов; не переносите скрыто чувствительные или серверные свойства. Проверьте лицензию выбранной версии AutoMapper. При проекциях IQueryable подтверждайте SQL-трансляцию у реального провайдера; объектный маппинг и проекция в SQL имеют разную семантику.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
