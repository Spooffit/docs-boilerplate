# Ручной маппинг / методы расширения

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Пишите понятные конструкторы, проекции или методы расширения C# на явных границах. Держите отображение простым, проверяйте нетривиальные преобразования, null, нормализацию и исключение чувствительных полей. Предпочитайте прямой код реальной сложности вместо рефлексивной инфраструктуры без необходимости.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
