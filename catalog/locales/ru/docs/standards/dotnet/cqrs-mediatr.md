# CQRS с MediatR

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Используйте MediatR для внутрипроцессной диспетчеризации команд и запросов, не выдавая его за транспортную шину. Pipeline behaviors добавляйте для настоящих сквозных задач. До внедрения проверьте условия лицензии и пакетов выбранной версии MediatR. Тестируйте регистрацию, наличие нужного handler, отмену и поведение приложения.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
