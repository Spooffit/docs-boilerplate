# Пулинг соединений PgBouncer

**Применяется только при явном выборе соответствующего профиля.**

## Правила

PgBouncer — пулер соединений PostgreSQL. Выбирайте session/transaction/statement pooling по реальному поведению клиента. Session pooling сохраняет состояние сеанса; transaction pooling может нарушать использование session-level возможностей, поэтому проверьте prepared statements, временные таблицы, настройки сеанса, advisory locks и ORM-драйвер. Размеры пулов определяйте по измеренному параллелизму. Настройте TLS, минимальные привилегии и метрики; проверяйте failover, тайм-ауты и миграции через пулер. Источник: https://www.pgbouncer.org/features.html

## Проверка

Фиксируйте реальные версии, параметры и результаты тестов. Шаблон не утверждает их за проект.
