# Пулинг соединений PgBouncer

**Применимость:** PostgreSQL с явно выбранным PgBouncer. Без измерений нагрузки этот документ не задаёт готовую production-конфигурацию.

## Контракт пулера

- Явно выберите режим `session`, `transaction` или `statement`. Session сохраняет состояние серверного соединения для клиентской сессии. Transaction возвращает соединение в пул после транзакции; statement сильнее ограничивает семантику транзакций и не подходит для многооператорных транзакций.
- До transaction pooling проверьте временные таблицы, session `SET`, `LISTEN/NOTIFY`, session-level advisory locks и подготовленные выражения. Совместимость prepared statements зависит от версии PgBouncer, протокола и `max_prepared_statements`; универсальные утверждения о поддержке или несовместимости недопустимы.
- Тестируйте фактические версии Npgsql/EF Core/Dapper через пулер: auto-prepare, транзакции, отмену, тайм-ауты и миграции схемы. Отдельно определите подключение для миграций и административных операций: некоторым нужен session/direct connection.

## Ёмкость и безопасность

- Рассчитывайте серверные соединения с учётом всех экземпляров пулера, баз, пользователей, приложений и административного резерва. Настраивайте `default_pool_size`, `max_client_conn` и прочие лимиты по измеренным параллельным запросам, очередям и `max_connections` PostgreSQL. Универсальных чисел нет.
- Определите аутентификацию, ротацию учётных данных, TLS на нужных участках, хранение секретов и минимальные привилегии. Не публикуйте пароли и небезопасные учётные данные в примерах.
- Опишите readiness, остановку с дренированием и failover PostgreSQL. Доступность порта PgBouncer сама по себе не гарантирует доступности базы.

## Проверка

На реальной конфигурации проверьте конкуренцию запросов, насыщение пула, ожидание в очереди, перезапуск базы, rollback, отмену, prepared statements, миграции и SQL, зависящий от сессии. Зафиксируйте версии, режим, конфигурацию, команды проверки, результаты и метрики активных/свободных/ожидающих соединений. Валидация Markdown не доказывает работоспособность пула.

Источники: [возможности PgBouncer](https://www.pgbouncer.org/features.html), [конфигурация](https://www.pgbouncer.org/config.html).
