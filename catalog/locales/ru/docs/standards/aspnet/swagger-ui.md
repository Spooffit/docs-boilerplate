# Swagger UI для ASP.NET Core

**Применяется только при выборе профиля.** Не является утверждённой архитектурой проекта.

## Рекомендации

Swagger UI — интерфейс просмотра OpenAPI, не генератор спецификации. Настраивайте Microsoft.AspNetCore.OpenApi или Swashbuckle независимо. Ограничьте доступ средой или авторизацией; проверьте маршрут документа и схемы безопасности.

## Проверка

Сверьте версии и реальные контракты. Отдельно проверяйте интеграции и безопасность.
