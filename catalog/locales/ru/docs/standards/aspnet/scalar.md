# Scalar API Reference для ASP.NET Core

**Применяется только при выборе профиля.** Не является утверждённой архитектурой проекта.

## Рекомендации

Scalar.AspNetCore отображает существующий OpenAPI из Microsoft или Swashbuckle. Настройте MapScalarApiReference и правильный маршрут OpenAPI. Ограничьте доступ; не помещайте рабочие секреты в интерфейс.

## Проверка

Сверьте версии и реальные контракты. Отдельно проверяйте интеграции и безопасность.
