# Соглашения для компонентов MudBlazor

**Применяется только при выборе MudBlazor.** Не означает, что вся разметка обязана состоять из MudBlazor-компонентов.

## Компоненты и состояние

Выбирайте компонент по доступной семантике и реальным потребностям интерфейса. Обрабатывайте двустороннее связывание и изменения параметров без незаметной перезаписи пользовательского ввода. Не создавайте отдельное состояние только ради обёртки.

## Темы и доступность

Используйте согласованную систему тем и токенов; проверяйте контраст, подписи, ошибки форм, клавиатуру и фокус. Скрытие действия в UI не заменяет серверные разрешения.

## Проверка

Изолированно проверяйте события и параметры компонентов. При сложном JS, overlay, диалогах, popover и keyboard behavior используйте реальный браузер. Проверяйте выбранные версии пакетов и breaking changes.
