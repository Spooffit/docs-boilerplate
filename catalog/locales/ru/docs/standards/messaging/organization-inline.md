# Точки приёма сообщений в приложении

**Применяется только при явном выборе соответствующего профиля.**

## Правила

Размещайте обработчики и точки приёма сообщений внутри приложения или модуля-владельца. Разделяйте только действительно устойчивые DTO интеграций между потребителями. Транспорт и библиотека выбираются отдельно; не создавайте обязательную иерархию проектов для небольших систем. Проверяйте реальную композицию и топологию брокера.

## Проверка

Фиксируйте реальные версии, параметры и результаты тестов. Шаблон не утверждает их за проект.
