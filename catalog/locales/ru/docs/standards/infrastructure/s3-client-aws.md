# Клиент S3: AWS SDK for .NET

**Заготовка, а не проверенный пример реализации.** Применяется при явном выборе AWS SDK for .NET S3, в том числе для совместимых endpoint, где это поддерживается.

Укажите действующие версии SDK и API, источник credentials, регион и endpoint, TLS, таймауты, повторы и multipart. Для не-AWS хранилищ проверяйте совместимость конкретного поставщика и используемых операций: S3-реализации различаются.

Не сохраняйте в документации секреты и производственные адреса. Выбор клиентского SDK **не означает развёртывание AWS S3**.

См. [AWS SDK for .NET S3](https://docs.aws.amazon.com/sdk-for-net/v3/developer-guide/s3-apis-intro.html).
