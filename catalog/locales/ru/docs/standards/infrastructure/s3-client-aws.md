# S3-клиент AWS SDK for .NET

**Заготовка, а не проверенный пример реализации.** Применяется к приложениям, явно использующим S3-клиент AWS SDK for .NET, в том числе с настроенным S3-совместимым endpoint, если он поддерживается.

Зафиксируйте настоящие версии SDK и API, источник учётных данных, конфигурацию региона/endpoint, TLS, тайм-ауты запросов, повторы и многочастную загрузку. Для хранилищ вне AWS проверяйте совместимость с конкретным поставщиком и функциями, а не предполагайте одинаковое поведение всех реализаций S3.

Не встраивайте учётные данные или рабочие endpoints в код и не считайте выбор клиента автоматическим развёртыванием Amazon S3.

Источник: [AWS SDK for .NET S3](https://docs.aws.amazon.com/sdk-for-net/v3/developer-guide/s3-apis-intro.html).
