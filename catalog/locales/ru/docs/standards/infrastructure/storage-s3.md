# S3-совместимое объектное хранилище

**Заготовка, не готовый производственный стандарт.** Выбирайте профиль, когда инфраструктура проекта действительно использует API S3, включая совместимые endpoint.

Документируйте конкретный сервис или поставщика, адрес и TLS, владельцев bucket и политики доступа, источник секретов и ротацию ключей, правила жизненного цикла, retention, multipart, наблюдаемость, резервное копирование и восстановление. Чётко различайте **сервис хранения** (например, сервер MinIO или AWS S3) и **клиентскую библиотеку приложения**.

Не вставляйте в универсальный шаблон настоящий адрес, ключ доступа, имя bucket или команду развёртывания. Совместимость по функциям S3 подтверждайте для конкретного поставщика и версии.

Общий стандарт безопасной передачи, авторизации и очистки объектов включается зависимостью. Выбор S3 не означает автоматический выбор SDK.
