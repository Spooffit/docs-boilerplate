# Хранилище метрик Grafana Mimir

**Применяется только при выборе профиля.** Не является утверждённой архитектурой проекта.

## Рекомендации

Mimir — масштабируемый backend метрик, совместимый с Prometheus. Определяйте ingestion, remote-write, объектное хранение, retention, изоляцию арендаторов и запросы для реальной топологии. Не смешивайте Mimir со сбором Prometheus и Alloy.

## Проверка

Сверьте версии и реальные контракты. Отдельно проверяйте интеграции и безопасность.
