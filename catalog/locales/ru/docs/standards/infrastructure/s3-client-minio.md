# Клиент S3: MinIO .NET SDK

**Заготовка, а не проверенный пример реализации.** Применяется только при явном выборе клиентской библиотеки MinIO .NET для S3-совместимого сервиса.

Укажите реальную версию SDK, endpoint, TLS, настройки региона, источник credentials, отмену, таймауты, повторы и multipart. Проверяйте взаимодействие именно с выбранным хранилищем: выбор SDK не разворачивает сервер MinIO.

Используйте поддерживаемые публичные API установленной версии. Ошибки доступа, незавершённые загрузки, неопределённость после повторов и видимость объекта обрабатывайте по принятому контракту приложения. Не помещайте секреты и произвольные имена bucket в шаблон.

См. [MinIO .NET SDK](https://github.com/minio/minio-dotnet).
