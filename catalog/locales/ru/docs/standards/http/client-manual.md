# Ручные REST API-клиенты

**Применимость:** этот вариант выбирается явно в мастере и не подтверждает наличие реализации.

## Рекомендации

Используйте типизированную обёртку HttpClient с DI, управлением handlers и явными тайм-аутами. Опирайтесь на утверждённый контракт сервера для DTO, маршрутов, заголовков и ошибок. Не повторяйте автоматически запись с неопределённым исходом. Проверяйте сериализацию и обработку статусов на реальном или контрактно точном сервере.

## Проверка

Фиксируйте только реальные версии, источники и выполненные тесты. Не переносите специфичные для старого продукта сущности и статусы в универсальный шаблон.
