# REST API-клиенты NSwag

**Применяется только при выборе профиля.** Не является утверждённой архитектурой проекта.

## Рекомендации

Генерируйте типизированные клиенты по версионированному OpenAPI с закреплёнными инструментами. Отделяйте сгенерированный код от ручного; проверяйте nullable, ошибки, время жизни HttpClient и фактическую совместимость с сервером.

## Проверка

Сверьте версии и реальные контракты. Отдельно проверяйте интеграции и безопасность.
