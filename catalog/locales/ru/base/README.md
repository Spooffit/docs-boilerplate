## Завершение инициализации с ИИ-агентом

Если существует файл bootstrap.md, выбор технологий завершён, но **исследование самого проекта ещё не закончено**. Попросите ИИ-агента выполнить инструкции из этого файла и временного опросника. Агент уточнит цели, связанные системы, интеграции, реальные этапы работ и терминологию, а после вашего согласования заполнит постоянные документы проекта.

Только после явного подтверждения итогов второго этапа удалите временные файлы командой `docs-boilerplate bootstrap-complete --output <repository-root> --apply`. Сначала можно посмотреть план удаления без параметра `--apply`. Шаблоны, стандарты, AGENTS.md и постоянные Agent Skills останутся.
