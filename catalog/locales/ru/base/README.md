## Завершение инициализации с ИИ-агентом

Если существует `bootstrap.md`, технические профили уже выбраны, но **изучение проекта ещё не завершено**. Попросите ИИ-агента выполнить временные инструкции и опросник. Агент уточнит цели, связанные системы, интеграционные ограничения, фактические этапы и терминологию, а затем с вашего одобрения заполнит постоянную документацию проекта и архитектуры.

Только после вашего подтверждения итогов второго этапа удалите временные файлы командой `docs-boilerplate bootstrap-complete --output <repository-root> --apply`. Постоянные шаблоны, стандарты, инструкции и выбранные навыки агентов сохраняются. Перед удалением можно просмотреть план без `--apply`.
