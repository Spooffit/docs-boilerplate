# {{PROJECT_NAME}}


Добро пожаловать в документацию. Начните с [обзора проекта](project/overview.md), [обзора архитектуры](architecture/overview.md) и [выбранных инженерных стандартов](standards/index.md).

В [каталоге документации](catalog.md) перечислены **установленные** стандарты и заготовки проектных разделов. Обращайтесь к [руководству по шаблонам](templates/index.md), только когда действительно нужен новый документ. Не выводите требования из пустых шаблонов.

Основные инструкции проекта находятся в корневых файлах [AGENTS.md](../AGENTS.md) и [llms.txt](../llms.txt).

Обзор проекта описывает подтверждённые требования. Архитектурные решения фиксируются в ADR. Примеры из шаблонов не являются доказательством существующей реализации.
