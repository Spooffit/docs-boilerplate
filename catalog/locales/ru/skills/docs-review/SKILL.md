# Проверка документации

1. Определите текущую задачу и применимые источники. Не перечитывайте все документы без необходимости.
2. Сравните описанное поведение с принятыми требованиями, реальным кодом, тестами и контрактами в конкретной версии.
3. Найдите противоречия, неподтверждённые утверждения, неработающие ссылки, отсутствующие ID, ошибочные статусы и дублирование нормативных правил.
4. Проверяйте, что установленный профиль не объявлен доказательством реализации, а примеры кода не выданы за проверенные.
5. Разделяйте критические ошибки, замечания и неизвестное; приводите путь документа и основание каждого замечания.
6. Запускайте `validate` при доступности генератора. Сообщайте, что успешная проверка синтаксиса не подтверждает фактическую корректность.
