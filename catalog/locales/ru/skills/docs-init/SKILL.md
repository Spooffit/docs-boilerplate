# Первичное создание документации проекта

Этот навык может быть установлен **в уже созданном репозитории**. Тогда не запускайте init повторно и не предполагаете наличие CLI. Изучайте существующий проект и дополняйте документацию. Генератор применяется только к новому каталогу из отдельного исходного репозитория.

1. Подтвердите назначение проекта и место назначения. Изучите реальные требования, решения, исходники, контракты и результаты тестов. Не выдумывайте факты.
2. Уточняйте критические неизвестные решения, когда без них нельзя продолжить. Неизвестную технологию и поведение помечайте «Не проверено».
3. Для нового каталога используйте `docs-boilerplate list`, если инструмент установлен; иначе запустите `dotnet run --project src/DocsBoilerplate.Cli -- list` **из исходного репозитория генератора** при наличии .NET 10.
4. Для нового каталога сначала выполните `init --dry-run`; проверьте профили, выбранный язык `--language ru|en` и отсутствие пересечений файлов. Затем запустите init, который автоматически проверяет результат. Docsify создаёт только index.html; `--site none` отключает просмотрщик.
5. Прочитайте `llms.txt`, `AGENTS.md`, `docs/index.md`, `docs/catalog.md`, `docs.config.json`; сопоставьте установленные файлы с выбранными профилями.
6. На первом этапе наполнения проекта уточните `docs/project/overview.md` и `docs/architecture/overview.md` по реальным источникам. Отделяйте наблюдаемую реализацию от принятых решений и открытых вопросов. До проверки сохраняйте `draft`.
7. Создавайте только необходимые Feature, Technical Feature, Module, Question, Milestone или ADR, выбирая минимальный шаблон из `docs/templates/index.md`. Не создавайте пустые семейства документов.
8. При доступном генераторе запускайте `validate` после правок; без него проверяйте навигацию и метаданные вручную. Не редактируйте `docs.config.json` вручную.
9. Сообщите установленные профили, источники и фактические тесты, черновики и неизвестное. Используйте штатное обновление с предварительным просмотром вместо самостоятельного изменения хешей.
