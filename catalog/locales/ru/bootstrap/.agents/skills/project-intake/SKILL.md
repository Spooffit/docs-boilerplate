# Изучение проекта (временный навык)

Используйте только пока существует `bootstrap.md`. Сначала прочитайте его, затем используйте `.agents/bootstrap/questionnaire.md` для адаптивного интервью и `.agents/bootstrap/finish-checklist.md` для проверки завершения.

Уточните проблему, цели, связанные репозитории, зависимые сервисы и контракты, существующую архитектуру, инфраструктуру, этапы и полезные термины глоссария. Задавайте уточнения по ситуации, отделяйте неизвестное от проверенного и не придумывайте бизнес-логику, даты, ответственных или технические реализации.

Редактируйте **постоянные** обзорные документы проекта и архитектуры, добавляйте только нужные страницы и исправляйте навигацию. Запросите согласование полученного базового набора документов. Затем выполните явную очистку `bootstrap-complete --apply`, которая проверяет байтовое содержимое перед удалением временных материалов. Не удаляйте другие навыки или проектные документы. Если установленный CLI недоступен, не утверждайте, что очистка была выполнена.
