# Первичное исследование проекта

Используйте этот навык только при наличии `bootstrap.md`. После завершения и одобренной очистки он не должен восстанавливаться автоматически.

1. Прочитайте постоянные инструкции `AGENTS.md` и временный опросник `.agents/bootstrap/questionnaire.md`.
2. Задавайте вопросы небольшими блоками с учётом ответов; допускайте неизвестное и неприменимое.
3. Изучайте реальные исходники, контракты и выполненные проверки, если они доступны. Не превращайте установленный профиль в доказательство реализации.
4. Наполните проектные документы только проверенными фактами, сохраняя `draft` там, где данные ещё не утверждены.
5. Назовите оставшиеся неизвестные вопросы и предложите пользователю проверить итог.
6. Не выполняйте `bootstrap-complete --apply` без явного разрешения владельца. Не удаляйте пользовательские изменения.
7. После одобрения выполните предварительный просмотр и очистку штатным инструментом, затем доступную валидацию. Постоянные инструкции и навыки должны остаться.
