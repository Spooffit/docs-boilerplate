## Окружение и fixtures

Первый Player выбран: Unity 2022.3.62f3, Windows x64/IL2CPP. До запуска фиксируются stripping/build settings, SDK/package/native set и CM/proxy/TLS configuration; совместимость проверяется реальным Player. Demo CM — один процесс с постоянной PostgreSQL и private MinIO. In-memory планы переживают client restart, но теряются при CM restart.

Каждая проверка владеет своими records/assets/object locations/plan IDs/client-store partitions/Unity resources; cleanup только своих данных. Races проверяются barriers/fault injection/process restart, не случайным Sleep. Production seeds/broker/VR School/Identity/licenses не обязательны.

Representative fixture включает все 15 типов: required/optional/missing, zero/false, пустой FlagEnum/List, deprecated options/fields, прозрачный RGBA, signed TimeSpan, naive DateTime/7 fractional digits, large long/precise decimal без double conversion, non-ASCII/escaping/restricted HTML. Есть Object/List<Object>/List<List>, orphan reconciliation, две exact Published versions одной schema и разные instance target contexts. Media содержит real Image и Audio/Video HTTP fixtures с корректными/ложными signatures.

## Границы подтверждения

HTTP/3 preference и HTTP/2 fallback сохраняют ID/plan/cursor; actual capability подтверждается выбранным Unity/proxy/TLS контуром. Editor run не Player/AOT proof; package publish не clean installation proof; SQLite atomicity documentation не доказательство выбранного Unity adapter/platform.

Для старта F19 не нужны MVP CLI/expanded compatibility/auth/integrations. Отдельная F23 Addressables включена в Demo решением владельца 11.10.2026; её приёмка выполняется отдельно, без обратной зависимости основного F19 package. Для объявления Demo готовым нужны применимые реальные проверки таблицы и зафиксированное окружение; static source inventory/docs validation не заменяют их.
