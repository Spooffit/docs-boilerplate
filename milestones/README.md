# Каталог milestones

**Текущий milestone: [Demo](demo/demo.md).**

[Проверка готовности Demo к реализации](demo/demo-readiness.md) отражает согласованные решения 1–42 и оставшуюся инженерную материализацию контрактов. [Матрица приёмки](demo/demo-acceptance.md) задаёт необходимые реальные проверки. Оба документа не подтверждают наличие работающей реализации.

Milestones задают последовательность Demo → MVP → Production и состав фич каждого этапа. Это границы результата, а не отчёт о готовности кода, сроки, исполнители или задачи GitLab. Одна фича может участвовать в нескольких milestones с разной глубиной.

| Milestone | Цель | Состав и границы |
| --- | --- | --- |
| [Demo](demo/demo.md) | Проверить базовую цепочку CM и требования вместе с заказчиком | F01–F05, F13, минимальная F14, F19–F23; без входа, лицензий, шины и полного Publishing |
| [MVP](mvp/mvp.md) | Собрать полный согласованный продуктовый процесс после обратной связи по Demo | Развитие базовых фич, F06–F12, F15–F18, CLI F22; F20 остаётся примером |
| [Production](production/production.md) | Подготовить результат MVP к рабочему использованию | База MVP; границы дополнительного developer workflow и критерии эксплуатационной готовности ещё уточняются |

## Как пользоваться

[Архитектура Launcher/media delivery](../technical/frontend/questions/Q37-launcher-asset-delivery.md) относится к интеграционному этапу после Demo. Предложение MVP integration → Production hardening отражено в файлах этапов как рабочая декомпозиция; точное распределение объёма и сроки ещё не утверждены. Demo остаётся самостоятельным, current milestone не меняется.

Подробный перечень входящих фич, глубина реализации и исключения текущего этапа находятся в [Demo](demo/demo.md). При изменении состава обновляется соответствующий milestone-файл; текущий milestone выбирается здесь. Требования и алгоритмы самих фич остаются в [каталоге фич](../features.md) и F-документах, связи — в [каталоге модулей](../modules.md).

F23 — отдельный optional Addressables add-on, включённый владельцем в Demo 11.10.2026. Его реализуют отдельной фичей после текущего этапа F19; основной SDK остаётся независимым от add-on. Расширенная совместимость F14 и дополнительные SDK/Editor/source-generator/CI consumers не включаются в milestone автоматически. Их объём фиксируется после соответствующего решения в F/Q и переносится в нужный milestone.
