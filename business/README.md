# Бизнесовая документация

Раздел определяет назначение продукта, язык предметной области и наблюдаемый результат функций. Технологии хранения и детали UI не заменяют бизнесовое правило.

## Структура раздела

| Место | Содержание |
| --- | --- |
| [Описание продукта](product.md) | Проблема, пользователи и границы результата. |
| [Словарь](glossary.md) | Значение терминов, используемых во всех разделах. |
| `features/` | Отдельные F-спецификации: участники, условия, сценарии и критерии приёмки. |
| `modules/` | Назначение модуля и связи между его функциями. |
| `questions/` | Отдельные бизнесовые вопросы и ответы на них. |
| `adr/` | Причины принятых предметных и архитектурных решений. |

Для функции используйте [карту фич](../features.md), для более широкой области [карту модулей](../modules.md). Неизвестное находится в [каталоге вопросов](../questions.md). Документы бэкенда и фронтенда связаны с бизнесовыми функциями теми же F-ID.

Реализация и готовность API не выводятся из наличия бизнесового описания. Подробная совместимость клиента остаётся отдельной отложенной темой, указанной в соответствующей фиче и вопросе.
