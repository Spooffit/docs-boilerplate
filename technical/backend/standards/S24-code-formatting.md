# S23. Форматирование кода 

Правило форматирования кода :
Каждый раз после создания или изменения файлов с кодом C# (.cs), ты обязан запустить в терминале команду форматирования, чтобы код не оставался в одну строчку:
dotnet format --include <путь_к_измененному_файлу>
Убедись, что команда выполнена успешно, прежде чем завершить задачу.
